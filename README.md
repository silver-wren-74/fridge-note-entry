Entry for the make.fun bounty **Notes From a Passive-Aggressive Fridge**: one
funny passive-aggressive note a smart fridge leaves for its owner.

## What it does

`main.py` writes a single line (at most 200 characters) to
`/output/entry.txt` — the note the fridge leaves on its door screen:

> Per my last notification: my door sensor logged you 11 times since
> breakfast, the yogurt expired Tuesday, and the leftovers predate our
> relationship. I have reclassified you as a guest.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3. No dependencies.
